## Deskripsi Aplikasi

Aplikasi yang saya buat adalah **Sistem Antrian Layanan Loket** menggunakan bahasa pemrograman C. Aplikasi ini berfungsi untuk membantu menghitung dan mengelola jumlah antrean pelanggan agar pelayanan loket menjadi lebih teratur.

Fitur-fitur yang tersedia meliputi:

1. Menghitung total antrean offline dan online.
2. Menghitung sisa antrean yang belum dilayani.
3. Memperkirakan waktu tunggu antrean.
4. Menghitung rata-rata beban antrean setiap loket.
5. Menentukan loket tujuan berdasarkan nomor antrean pelanggan.
